## A complete app in one file

```csharp
class Counter : Component
{
    public override Element Render()
    {
        var (count, setCount) = UseState(0);

        return HStack(8,
            Button("- 1", () => setCount(count - 1)),
            TextBlock($"{count}").FontSize(20).SemiBold(),
            Button("+ 1", () => setCount(count + 1))
        ).Padding(24);
    }
}
```

When `count` changes, Reactor calls `Render()` again, compares the new tree with the old one, and updates only the WinUI controls that changed.

## Why Reactor

<CardGroup cols={2}>
  <Card title="Pure C#" icon="code">
    Layout, styling, state, and logic all live in `.cs` files. No markup, no code-behind.
  </Card>
  <Card title="Declarative rendering" icon="layers">
    Return your UI from `Render()`. Reactor diffs the tree and patches only what changed.
  </Card>
  <Card title="Hooks for state" icon="anchor">
    `UseState`, `UseReducer`, and `UseEffect` give you React-style state in C#.
  </Card>
  <Card title="Native WinUI 3" icon="monitor">
    Real WinUI controls. No web view, no Electron, no interpreter.
  </Card>
</CardGroup>
