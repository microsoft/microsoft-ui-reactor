# Markdown

Markdown rendering options, parser callbacks and text selection. From the Microsoft.UI.Reactor.Advanced package.

These types ship in the `Microsoft.UI.Reactor.Advanced` package. Call the `Markdown` factory to render a Markdown string.

**Learn more:** [Text and Media](../../text-and-media.md)
