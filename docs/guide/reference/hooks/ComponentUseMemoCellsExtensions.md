# ComponentUseMemoCellsExtensions

`type`  
_cref_: `T:Microsoft.UI.Reactor.Hooks.ComponentUseMemoCellsExtensions`

## Summary

`Component`-class shims for [UseMemoCellsExtensions](UseMemoCellsExtensions.md)
so subclasses can call <c>UseMemoCells</c> without going through
<c>this.Context</c>. Same semantics as the `RenderContext`
extension methods.
