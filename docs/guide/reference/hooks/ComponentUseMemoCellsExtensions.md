## Summary

`Component`-class shims for [UseMemoCellsExtensions](UseMemoCellsExtensions.md) ([guide](../../hooks.md))
so subclasses can call `UseMemoCells` without going through
`this.Context`. Same semantics as the `RenderContext`
extension methods.
