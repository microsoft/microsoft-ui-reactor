# UseMultipleFilesPickerAsync

`method`  
_cref_: `M:Microsoft.UI.Reactor.Core.RenderContext.UseMultipleFilesPickerAsync(Microsoft.UI.Reactor.Core.FilePickerOptions)`

> **Learn more:** [Hooks](../../hooks.md), [Effects](../../effects.md)

## Summary

Opens a multiple-file picker on the owning window's UI thread.

## Discussion

Call from an event handler, not during Render. Cancellation returns an empty list.
