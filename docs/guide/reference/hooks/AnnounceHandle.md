# AnnounceHandle

`type`  
_cref_: `T:Microsoft.UI.Reactor.Hooks.AnnounceHandle`

## Summary

Handle returned by [UseAnnounce](UseAnnounce.md).
Provides an imperative [Announce](Announce.md) method for screen reader
live-region announcements plus a zero-size [Region](Region.md) element
that must be included somewhere in the component's rendered tree.
