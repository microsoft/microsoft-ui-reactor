# Layout

The flex panel, grid sizes and the attached layout records.

**Learn more:** [Layout](../../layout.md), [Flex Layout](../../flex-layout.md)

## Types

| Type | Description |
| --- | --- |
| [Attached layout properties](attached.md) | Records that hold the attached properties set by the layout modifiers. |
| [Flex enums](flex-enums.md) | Enums that control the flex layout. |
| [`GridSize`](GridSize.md) | Strongly-typed grid track size, used by the typed `Microsoft.UI.Reactor.Factories.Grid(GridSize[], GridSize[], Element?[])` factory in place of the legacy string-form (`"Auto"`, `"*"`, `"200"`, `"1.5*"`) tracks. |
| [`GridSizeExtensions`](GridSizeExtensions.md) | Fluent extension methods for `GridSize` to set the optional `Min` and `Max` properties. |
