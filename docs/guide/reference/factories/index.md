# Factories

The DSL factory methods that create element records.

Add `using static Microsoft.UI.Reactor.Factories;` and call these methods to build an element tree, for example `VStack(TextBlock("Hello"), Button("OK", onClick))`.

**Learn more:** [Controls](../../controls.md), [Layout](../../layout.md), [Cheat Sheet](../../cheat-sheet.md)
