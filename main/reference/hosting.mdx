`ReactorApp` starts the app and opens its first window. The other types here describe windows, the tray icon, the taskbar and the ways to host Reactor inside an existing WinUI app.

**Learn more:** [Windows](/microsoft-ui-reactor/main/guides/windows), [Advanced Windowing](/microsoft-ui-reactor/main/guides/windowing-advanced)

## Types [#types]

| Type | Description |
| --- | --- |
| [Displays](/microsoft-ui-reactor/main/reference/hosting/displays) | Information about the connected displays. |
| [File pickers](/microsoft-ui-reactor/main/reference/hosting/file-pickers) | Options for the open file, save file and folder pickers. |
| [Launch and activation](/microsoft-ui-reactor/main/reference/hosting/launch) | How the app was started, and requests to embed it. |
| [Persistence](/microsoft-ui-reactor/main/reference/hosting/persistence) | Stores and scopes that save window placement and persisted state. |
| [Taskbar and jump lists](/microsoft-ui-reactor/main/reference/hosting/taskbar) | Types for the taskbar button, its progress, overlay, thumbnail buttons and jump list. |
| [Tray icon](/microsoft-ui-reactor/main/reference/hosting/tray-icon) | Types for an icon in the notification area. |
| [Window events](/microsoft-ui-reactor/main/reference/hosting/window-events) | Event arguments raised by a Reactor window. |
| [Window options](/microsoft-ui-reactor/main/reference/hosting/window-options) | Enums that describe the style, size and position of a window. |
| [XAML interop](/microsoft-ui-reactor/main/reference/hosting/xaml-interop) | Helpers for hosting Reactor inside an existing XAML app. |
| [`ReactorApp`](/microsoft-ui-reactor/main/reference/hosting/ReactorApp) |  |
| [`ReactorAppContext`](/microsoft-ui-reactor/main/reference/hosting/ReactorAppContext) | The argument to `ReactorApp.Run`'s startup callback. |
| [`ReactorApplication`](/microsoft-ui-reactor/main/reference/hosting/ReactorApplication) | Application subclass that implements IXamlMetadataProvider so the native XAML schema context can resolve managed types from XBF theme resources. |
| [`ReactorHost`](/microsoft-ui-reactor/main/reference/hosting/ReactorHost) | Hosts a Reactor component tree inside a WinUI Window. |
| [`ReactorHostControl`](/microsoft-ui-reactor/main/reference/hosting/ReactorHostControl) | A fully self-contained WinUI ContentControl that hosts a Reactor component tree. |
| [`ReactorWindow`](/microsoft-ui-reactor/main/reference/hosting/ReactorWindow) | Owns one OS top-level Window and one `ReactorHost`. |
| [`RenderStats`](/microsoft-ui-reactor/main/reference/hosting/RenderStats) | Snapshot of render loop performance, updated every ~1 second by `ReactorHost`. |
| [`UIThreadOnlyAttribute`](/microsoft-ui-reactor/main/reference/hosting/UIThreadOnlyAttribute) | Marks a method or property setter that must be invoked on the UI thread — the annotated method (or the property's setter) calls `ThreadAffinity.ThrowIfNotOnUIThread`, which throws `InvalidOperationException` when reached from a background thread once the UI dispatcher has been captured. (The guard is a no-op before the first window bootstraps, while `ReactorApp.UIDispatcher` is still null.) Property getters are not guarded, so the REACTOR_THREAD_001 analyzer flags writes to an annotated property, not reads. |
| [`WindowIcon`](/microsoft-ui-reactor/main/reference/hosting/WindowIcon) | Abstraction over `AppWindow.SetIcon` and `AppWindow.SetIcon`. |
| [`WindowKey`](/microsoft-ui-reactor/main/reference/hosting/WindowKey) | Stable identity for a top-level surface within a process. |
| [`WindowSpec`](/microsoft-ui-reactor/main/reference/hosting/WindowSpec) | Immutable (init-only) declarative description of a top-level Reactor window. |
