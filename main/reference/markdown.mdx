These types ship in the `Microsoft.UI.Reactor.Advanced` package. Call the `Markdown` factory to render a Markdown string.

**Learn more:** [Text and Media](/microsoft-ui-reactor/main/controls/text-and-media)

## Types [#types]

| Type | Description |
| --- | --- |
| [Delegates](/microsoft-ui-reactor/main/reference/markdown/delegates) | The delegate types in this category. |
| [Enums](/microsoft-ui-reactor/main/reference/markdown/enums) | The enumerations in this category. |
| [Parser block and span details](/microsoft-ui-reactor/main/reference/markdown/parser-details) | Details the Markdown parser passes for each block and span. |
| [`MarkdownLink`](/microsoft-ui-reactor/main/reference/markdown/MarkdownLink) | A Markdown link passed to `MarkdownOptions.LinkBuilder`. |
| [`MarkdownOptions`](/microsoft-ui-reactor/main/reference/markdown/MarkdownOptions) | Options for customizing how markdown is rendered to Reactor elements. |
| [`MarkdownTextSelection`](/microsoft-ui-reactor/main/reference/markdown/MarkdownTextSelection) | Message-bounded, opt-in semantic text selection for Markdown and custom content. |
| [`MarkdownTextSelectionOptions`](/microsoft-ui-reactor/main/reference/markdown/MarkdownTextSelectionOptions) | Copy policy for one selection scope; a non-null parser value only enables semantic surfaces. |
