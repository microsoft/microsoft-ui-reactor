### `WithAlternateView` [#withalternateview]

Wraps any chart element with an alternate-view toggle. Pressing **T** or **Alt+Shift+F11** toggles between the chart and the alternate view (typically a data table). The currently-hidden view is removed from the accessibility tree so screen readers only see the active presentation.

Use this with raw D3 chart elements that are not built via [`ChartElement<T>`](/microsoft-ui-reactor/main/reference/charting/ChartElement) (which has its own `.AlternateView()` modifier).

```csharp
public static Element WithAlternateView(Element chartElement, Element alternateView)
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `chartElement` | [`Element`](/microsoft-ui-reactor/main/reference/elements/Element) | The chart element to wrap. |
| `alternateView` | [`Element`](/microsoft-ui-reactor/main/reference/elements/Element) | The alternate view element (e.g., a data table). |
