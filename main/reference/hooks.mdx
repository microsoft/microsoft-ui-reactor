Hooks are how Reactor components subscribe to state, schedule effects, and reach into the framework's lifecycle from a function-shaped `Render` body. Call them on the `RenderContext` (or from a `Component`), always in the same order, and never inside a condition or a loop.

**Learn more:** [Hooks](/microsoft-ui-reactor/main/guides/hooks), [Effects and Lifecycle](/microsoft-ui-reactor/main/guides/effects), [Rules of Reactor](/microsoft-ui-reactor/main/get-started/rules-of-reactor)

## State [#state]

Hooks that keep values between renders.

| Hook | Description |
| --- | --- |
| [`UseCollection`](/microsoft-ui-reactor/main/reference/hooks/UseCollection) | Subscribes to an ObservableCollection and re-renders on Add/Remove/Reset. |
| [`UseExternalStore`](/microsoft-ui-reactor/main/reference/hooks/UseExternalStore) | Subscribes to an external store that exposes a current snapshot getter. |
| [`UseObservable`](/microsoft-ui-reactor/main/reference/hooks/UseObservable) | Subscribes to an INotifyPropertyChanged source and re-renders when any property changes. |
| [`UseObservableProperty`](/microsoft-ui-reactor/main/reference/hooks/UseObservableProperty) | Subscribes to a specific property on an INotifyPropertyChanged source. |
| [`UseObservableTree`](/microsoft-ui-reactor/main/reference/hooks/UseObservableTree) | Observes an object and all nested INotifyPropertyChanged values reachable through its properties. |
| [`UsePersisted`](/microsoft-ui-reactor/main/reference/hooks/UsePersisted) | Like UseState, but the value survives unmount/remount via an in-memory cache. |
| [`UseReducer`](/microsoft-ui-reactor/main/reference/hooks/UseReducer) | Declares a piece of state with a functional updater variant. |
| [`UseRef`](/microsoft-ui-reactor/main/reference/hooks/UseRef) | Returns a mutable ref object that persists across renders. |
| [`UseState`](/microsoft-ui-reactor/main/reference/hooks/UseState) | Declares a piece of state. |

## Effects and memoization [#effects-and-memoization]

Hooks that run side effects or cache values between renders.

| Hook | Description |
| --- | --- |
| [`UseCallback`](/microsoft-ui-reactor/main/reference/hooks/UseCallback) | Returns a stable callback reference that doesn't change between renders. |
| [`UseEffect`](/microsoft-ui-reactor/main/reference/hooks/UseEffect) | Runs a side effect after render. |
| [`UseMemo`](/microsoft-ui-reactor/main/reference/hooks/UseMemo) | Memoizes a computed value, recomputing only when dependencies change. |
| [`UseMemoCells`](/microsoft-ui-reactor/main/reference/hooks/UseMemoCells) | Memoize cell construction for `items`. |
| [`UseMemoCellsByIndex`](/microsoft-ui-reactor/main/reference/hooks/UseMemoCellsByIndex) | Memoize cell construction when the data source already knows which indices changed. |
| [`UseMemoCellsByKey`](/microsoft-ui-reactor/main/reference/hooks/UseMemoCellsByKey) | Memoize cell construction keyed by `keySelector`. |

## Context [#context]

Hooks that read values provided higher in the tree.

| Hook | Description |
| --- | --- |
| [`UseContext`](/microsoft-ui-reactor/main/reference/hooks/UseContext) | Reads the nearest ancestor's provided value for the given context. |
| [`UseIntl`](/microsoft-ui-reactor/main/reference/hooks/UseIntl) | Returns an IntlAccessor for the current locale. |

## Data and commands [#data-and-commands]

Hooks that load data, run mutations and expose commands.

| Hook | Description |
| --- | --- |
| [`UseCommand`](/microsoft-ui-reactor/main/reference/hooks/UseCommand) | Processes a Command for use in a component. |
| [`UseDataSource`](/microsoft-ui-reactor/main/reference/hooks/UseDataSource) | Projects an `IDataSource<T>` through `UseInfiniteResource`, surfacing its pages as an `InfiniteResource<TItem>`. |
| [`UseInfiniteResource`](/microsoft-ui-reactor/main/reference/hooks/UseInfiniteResource) | Returns the `InfiniteResource<TItem>` owned by this hook slot. |
| [`UseMutation`](/microsoft-ui-reactor/main/reference/hooks/UseMutation) | Registers a `Mutation<TInput, TResult>` for this hook slot. |
| [`UseResource`](/microsoft-ui-reactor/main/reference/hooks/UseResource) | Runs an async fetch keyed on `deps`, returning an `AsyncValue<T>` that tracks the fetch's lifecycle. |

## Forms and validation [#forms-and-validation]

Hooks that connect a component to a validation context.

| Hook | Description |
| --- | --- |
| [`UseChildValidationContext`](/microsoft-ui-reactor/main/reference/hooks/UseChildValidationContext) | Creates a child validation context independent from any parent. |
| [`UseValidationContext`](/microsoft-ui-reactor/main/reference/hooks/UseValidationContext) | Returns the nearest ancestor's ValidationContext, or creates a new one scoped to this component. |

## Windows and display [#windows-and-display]

Hooks that read or change the window, the display and the tray icon.

| Hook | Description |
| --- | --- |
| [`UseBreakpoint`](/microsoft-ui-reactor/main/reference/hooks/UseBreakpoint) | Returns true when the given window's width is \>= minWidth. |
| [`UseClosingGuard`](/microsoft-ui-reactor/main/reference/hooks/UseClosingGuard) | Registers a synchronous "can the window close right now?" predicate. |
| [`UseDisplays`](/microsoft-ui-reactor/main/reference/hooks/UseDisplays) | Returns the current display snapshot and re-renders when the display layout changes. |
| [`UseDpi`](/microsoft-ui-reactor/main/reference/hooks/UseDpi) | Returns the current per-window DPI (`ReactorWindow.Dpi`) and re-renders on DPI change. |
| [`UseIsActive`](/microsoft-ui-reactor/main/reference/hooks/UseIsActive) | Subscribes to the host window's activation events and re-renders on change. |
| [`UseIsCovered`](/microsoft-ui-reactor/main/reference/hooks/UseIsCovered) | Returns a covered hint from the host window's z-order transitions and re-renders on change. |
| [`UseOpenWindow`](/microsoft-ui-reactor/main/reference/hooks/UseOpenWindow) | Open or reuse a secondary window keyed by `key`. |
| [`UseTrayIcon`](/microsoft-ui-reactor/main/reference/hooks/UseTrayIcon) | Open (or reuse-by-`TrayIconSpec.Key`) a system-tray icon scoped to the calling component. |
| [`UseWindow`](/microsoft-ui-reactor/main/reference/hooks/UseWindow) | Resolves the `ReactorWindow` whose host renders this component — including nested components and virtualized rows realized outside the host's render pass — or `null` when it has no owning window (tray-flyout content, `ReactorHostControl` embeds). |
| [`UseWindowAspectRatio`](/microsoft-ui-reactor/main/reference/hooks/UseWindowAspectRatio) | Applies a lifetime-bound width/height aspect lock to the owning window. |
| [`UseWindowDragMove`](/microsoft-ui-reactor/main/reference/hooks/UseWindowDragMove) | Returns a stable callback that starts a framework-managed window drag/move loop (cursor polling + `AppWindow.Move` at ~60Hz until the left mouse button is released). |
| [`UseWindowPosition`](/microsoft-ui-reactor/main/reference/hooks/UseWindowPosition) | Subscribes to the host window's `PositionChanged` event and re-renders on change. |
| [`UseWindowSize`](/microsoft-ui-reactor/main/reference/hooks/UseWindowSize) | Returns (width, height) of the given window and re-renders when the window resizes. |
| [`UseWindowState`](/microsoft-ui-reactor/main/reference/hooks/UseWindowState) | Subscribes to the host window's `StateChanged` event and re-renders on change. |

## Theme and accessibility [#theme-and-accessibility]

Hooks that follow the system theme and accessibility settings.

| Hook | Description |
| --- | --- |
| [`UseAnnounce`](/microsoft-ui-reactor/main/reference/hooks/UseAnnounce) | Creates an `AnnounceHandle` for making screen reader announcements. |
| [`UseColorScheme`](/microsoft-ui-reactor/main/reference/hooks/UseColorScheme) | Returns the app-global `ColorScheme` — `ColorScheme.Light` or `ColorScheme.Dark`, read from `Application.Current.RequestedTheme`. |
| [`UseHighContrast`](/microsoft-ui-reactor/main/reference/hooks/UseHighContrast) | Returns `true` when the system is in a High Contrast (forced colors) theme. |
| [`UseHighContrastScheme`](/microsoft-ui-reactor/main/reference/hooks/UseHighContrastScheme) | Returns the high contrast scheme name (e.g., "High Contrast Black", "High Contrast White") or `null` if not in high contrast mode. |
| [`UseIsDarkTheme`](/microsoft-ui-reactor/main/reference/hooks/UseIsDarkTheme) | Convenience wrapper — returns `true` when the app-global color scheme is `ColorScheme.Dark`. |
| [`UseReducedMotion`](/microsoft-ui-reactor/main/reference/hooks/UseReducedMotion) | Returns `true` when the user or system prefers reduced motion (e.g., Windows "Show animations" is off, or `SPI_GETCLIENTAREAANIMATION` returns false). |

## Focus and element refs [#focus-and-element-refs]

Hooks that move focus or reach a mounted control.

| Hook | Description |
| --- | --- |
| [`UseElementFocus`](/microsoft-ui-reactor/main/reference/hooks/UseElementFocus) | Creates (or retrieves) a component-scoped `ElementRef` and pairs it with a `RequestFocus` action. |
| [`UseElementRef`](/microsoft-ui-reactor/main/reference/hooks/UseElementRef) | Returns a stable `ElementRef<T>` for the current component scope. |
| [`UseFocus`](/microsoft-ui-reactor/main/reference/hooks/UseFocus) | Creates and returns a FocusManager scoped to this component. |
| [`UseFocusTrap`](/microsoft-ui-reactor/main/reference/hooks/UseFocusTrap) | Creates a focus trap handle that traps keyboard focus within a container when active. |

## Navigation [#navigation]

Hooks for page navigation and the system back button.

| Hook | Description |
| --- | --- |
| [`UseNavigation`](/microsoft-ui-reactor/main/reference/hooks/UseNavigation) | Child mode: retrieves an ancestor's `NavigationHandle<TRoute>` from context. |
| [`UseNavigationLifecycle`](/microsoft-ui-reactor/main/reference/hooks/UseNavigationLifecycle) | Registers lifecycle callbacks that fire during navigation events. |
| [`UseSystemBackButton`](/microsoft-ui-reactor/main/reference/hooks/UseSystemBackButton) | Subscribes to Alt+Left and VirtualKey.GoBack keyboard events on the given window's content to call `NavigationHandle.GoBack`. |

## Docking [#docking]

Hooks that read the dock layout and the enclosing pane. From the Microsoft.UI.Reactor.Advanced package.

| Hook | Description |
| --- | --- |
| [`UseActivePaneKey`](/microsoft-ui-reactor/main/reference/hooks/UseActivePaneKey) | Returns the active pane's `DockableContent.Key`, or null when no pane is active. |
| [`UseDockHost`](/microsoft-ui-reactor/main/reference/hooks/UseDockHost) | Returns the nearest enclosing `DockHostModel`, or null when the component is rendered outside any docking host. |
| [`UseDockLayout`](/microsoft-ui-reactor/main/reference/hooks/UseDockLayout) | Returns a wide snapshot of the dock layout — re-renders the consumer on any structural change. |
| [`UseDockPanePersisted`](/microsoft-ui-reactor/main/reference/hooks/UseDockPanePersisted) | Per-pane persisted state. |
| [`UseDockState`](/microsoft-ui-reactor/main/reference/hooks/UseDockState) | Returns the enclosing pane's current dock state (Docked / Floating / AutoHidden / AutoHiddenExpanded / Hidden). |
| [`UseIsActivePane`](/microsoft-ui-reactor/main/reference/hooks/UseIsActivePane) | Returns true when the \*enclosing pane\* is the host's currently-active pane. |
| [`UsePane`](/microsoft-ui-reactor/main/reference/hooks/UsePane) | Returns identity info for the enclosing pane subtree. |

## Win2D drawing [#win2d-drawing]

Hooks that keep Win2D draw state and device resources. From the Microsoft.UI.Reactor.Advanced package.

| Hook | Description |
| --- | --- |
| [`UseCanvasResources`](/microsoft-ui-reactor/main/reference/hooks/UseCanvasResources) | Creates resources for the current Win2D shared device, recreates them after `CanvasDevice.DeviceLost`, and disposes them on unmount. |
| [`UseDrawCommand`](/microsoft-ui-reactor/main/reference/hooks/UseDrawCommand) | Memoizes a Win2D draw callback and rebuilds it only when `deps` change. |
| [`UseDrawState`](/microsoft-ui-reactor/main/reference/hooks/UseDrawState) | Creates a stable mutable draw-state reference for Win2D callbacks. |
