## Types [#types]

| Type | Description |
| --- | --- |
| [Enums](/microsoft-ui-reactor/main/reference/theming/enums) | The enumerations in this category. |
| [`BackdropChoice`](/microsoft-ui-reactor/main/reference/theming/BackdropChoice) | Tagged value stored in `ElementModifiers.Backdrop`. |
| [`BrushHelper`](/microsoft-ui-reactor/main/reference/theming/BrushHelper) | Color and brush parsing utilities. |
| [`ResourceBuilder`](/microsoft-ui-reactor/main/reference/theming/ResourceBuilder) | Fluent builder for per-control resource overrides (WinUI lightweight styling). |
| [`ResourceOverrides`](/microsoft-ui-reactor/main/reference/theming/ResourceOverrides) | Immutable snapshot of per-control resource overrides built by `ResourceBuilder`. |
| [`Theme`](/microsoft-ui-reactor/main/reference/theming/Theme) | Provides semantic theme tokens and custom resource references. |
| [`ThemeRef`](/microsoft-ui-reactor/main/reference/theming/ThemeRef) | A reference to a WinUI theme resource that resolves at render time. |
| [`ThemeResource`](/microsoft-ui-reactor/main/reference/theming/ThemeResource) | Lookup helpers for WinUI theme resources. |
