## Types [#types]

| Type | Description |
| --- | --- |
| [Drag and drop](/microsoft-ui-reactor/main/reference/input/drag-and-drop) | Types for dragging data out of and dropping it onto elements. |
| [Element refs](/microsoft-ui-reactor/main/reference/input/element-refs) | Refs to mounted controls. |
| [Gestures](/microsoft-ui-reactor/main/reference/input/gestures) | Gesture events and their options. |
| [`Command`](/microsoft-ui-reactor/main/reference/input/Command) | Immutable (init-only) command descriptor that bundles an action with its metadata (label, icon, keyboard accelerator, enabled state). |
| [`Command<T>`](/microsoft-ui-reactor/main/reference/input/Command-1) | Immutable (init-only) parameterized command descriptor. |
| [`CommandInterop`](/microsoft-ui-reactor/main/reference/input/CommandInterop) | Bridges ICommand (MVVM/CommunityToolkit) to Command, enabling migration from ViewModel-based patterns to Reactor's declarative commanding. var reactorCmd = CommandInterop.FromCommand(viewModel.SaveCommand, "Save", icon: new SymbolIconData("Save"), accelerator: Accelerator(VirtualKey.S, Control)); |
| [`FocusManager`](/microsoft-ui-reactor/main/reference/input/FocusManager) | Imperative focus helpers (spec 027 Tier 5). |
| [`StandardCommand`](/microsoft-ui-reactor/main/reference/input/StandardCommand) | Factory methods for the 16 standard application commands with pre-filled metadata (label, icon, keyboard accelerator). |
