## `XamlHost` [#xamlhost]

Embeds an arbitrary [`FrameworkElement`](https://learn.microsoft.com/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.frameworkelement) (a UserControl, a custom control) created by `factory` on mount; `updater` runs after creation and on every update. Equivalent to `new XamlHostElement(factory, updater) { TypeKey = typeKey }`, but records the call site for the source map like every other factory.

```csharp
XamlHostElement XamlHost(Func<FrameworkElement> factory, Action<FrameworkElement>? updater = null, string? typeKey = null)
```

**Returns:** [`XamlHostElement`](/microsoft-ui-reactor/main/reference/elements/interop#xamlhostelement).

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `factory` | `Func<FrameworkElement>` |  | Creates the hosted control on mount. |
| `updater` | `Action<FrameworkElement>?` | `null` | Patches the hosted control after creation and on every update. |
| `typeKey` | `string?` | `null` | Discriminator for in-place updates: two hosts update in place only when their keys match, so unrelated hosted controls are not reconciled against each other. |

## `XamlPage` [#xamlpage]

Embeds an existing XAML [`Page`](https://learn.microsoft.com/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.page) in a [`Frame`](/microsoft-ui-reactor/main/reference/factories/navigation#frame), navigated to `pageType` with `parameter`. Re-navigates in place when either changes. Equivalent to `new XamlPageElement(pageType, parameter)`, but records the call site for the source map like every other factory.

```csharp
XamlPageElement XamlPage(Type pageType, object? parameter = null)
```

**Returns:** [`XamlPageElement`](/microsoft-ui-reactor/main/reference/elements/interop#xamlpageelement).

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `pageType` | `Type` |  |  |
| `parameter` | `object?` | `null` |  |
