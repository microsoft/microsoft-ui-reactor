Each factory method returns an element record. Most are on `Factories`, so `using static Microsoft.UI.Reactor.Factories;` covers them. A factory declared on another class names the `using static` it needs.

**Learn more:** [Commanding](/microsoft-ui-reactor/main/guides/commanding)

## `CommandHost` [#commandhost]

Scopes keyboard accelerators from the given commands to the child subtree. Only commands with an Accelerator produce keyboard accelerators on the host element.

