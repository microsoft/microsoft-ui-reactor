Modifiers are extension methods that return a changed copy of the element, so you can chain them.

**Learn more:** [Input and gestures](/microsoft-ui-reactor/main/guides/input-and-gestures), [Accessibility](/microsoft-ui-reactor/main/guides/accessibility)

## `AccessKey` [#accesskey]

Sets UIElement.AccessKey — the Alt+Key shortcut (underlined hint shown on Alt press). When used on a button bound to a [`Command`](/microsoft-ui-reactor/main/reference/input/Command), this per-site access key overrides [`Command.AccessKey`](/microsoft-ui-reactor/main/reference/input/Command#accesskey) (per-site override always wins).

```csharp
T AccessKey<T>(this T el, string key) where T : Element
```

Declared in `ElementExtensions`.

**Applies to:** any element.

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `key` | `string` |  |

**Example**

```csharp
Button("File", onClick).AccessKey("F")
```

## `TabNavigation` [#tabnavigation]

Sets UIElement.TabFocusNavigation — how Tab navigates within a container. Local = cycle within container. Once = enter once then leave. Cycle = loop forever.

```csharp
T TabNavigation<T>(this T el, KeyboardNavigationMode mode) where T : Element
```

Declared in `ElementExtensions`.

**Applies to:** any element.

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `mode` | `KeyboardNavigationMode` |  |

**Example**

```csharp
ToolBar(buttons).TabNavigation(KeyboardNavigationMode.Once)
```
