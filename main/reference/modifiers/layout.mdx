**Learn more:** [Layout](/microsoft-ui-reactor/main/guides/layout), [Flex Layout](/microsoft-ui-reactor/main/guides/flex-layout)

## `ViewChanged` [#viewchanged]

```csharp
ScrollViewElement ViewChanged(this ScrollViewElement el, Action? handler)
ScrollViewerElement ViewChanged(this ScrollViewerElement el, Action<ScrollViewerViewChangedEventArgs>? handler)
```

Declared in `ElementExtensions`.

| Overload | Description |
| --- | --- |
| `ViewChanged(ScrollViewElement, Action?)` | Wires the view-changed handler on the modern [`ScrollViewElement`](/microsoft-ui-reactor/main/reference/elements/layout#scrollviewelement). The modern control reports only settled values. Passing `null` clears. |
| `ViewChanged(ScrollViewerElement, Action<ScrollViewerViewChangedEventArgs>?)` | Wires the view-changed handler. Inspect `args.IsIntermediate` to debounce until the scroll settles. Passing `null` clears. |

**Applies to:** [`ScrollViewElement`](/microsoft-ui-reactor/main/reference/elements/layout#scrollviewelement), [`ScrollViewerElement`](/microsoft-ui-reactor/main/reference/elements/layout#scrollviewerelement).

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `handler` | `Action?` or `Action<ScrollViewerViewChangedEventArgs>?` |  |
