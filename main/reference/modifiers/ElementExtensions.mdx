---
title: "ElementExtensions"
description: "Fluent modifier extension methods for elements. Modifiers are stored inline on Element.Modifiers, preserving the concrete type through the entire fluent chain. This means .Set() works after any modifier:"
---

TextBlock("Hello") .Bold() .Margin(16) .HAlign(HorizontalAlignment.Center) .Set(tb =\> tb.IsTextScaleFactorEnabled = false) // still TextBlockElement!

The Set() extension gives strongly-typed native property access: Button("Click", onClick) .Set(b =\> b.FlowDirection = FlowDirection.RightToLeft)

```csharp
public static class ElementExtensions
```

Namespace: `Microsoft.UI.Reactor`.

## Methods [#methods]

### `Command` [#command]

Binds a [`Command`](/microsoft-ui-reactor/main/reference/input/Command) to an [`AppBarButtonData`](/microsoft-ui-reactor/main/reference/controls/menu-items#appbarbuttondata): maps Execute, IsEnabled, Icon, Accelerator, AccessKey, and Description — the same plumbing as the `AppBarButton(Command)` factory, but usable on a hand-built app-bar button. (issue #133)

```csharp
public static AppBarButtonData Command(this AppBarButtonData el, Command command)
```
