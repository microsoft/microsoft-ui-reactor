Every control in Reactor is described by an element record. Factory methods create them and modifiers return changed copies. The reconciler turns them into real WinUI controls.

**Learn more:** [Controls](/microsoft-ui-reactor/main/controls), [Reconciliation](/microsoft-ui-reactor/main/how-it-works/reconciliation)

## Types [#types]

| Type | Description |
| --- | --- |
| [`Element`](/microsoft-ui-reactor/main/reference/elements/Element) | A lightweight, immutable description of a UI node (the "virtual DOM"). |
