---
title: "ReactorApplication"
description: "Application subclass that implements IXamlMetadataProvider so the native XAML schema context can resolve managed types from XBF theme resources. No App.xaml needed — XamlControlsResources are loaded programmatically. The IXamlMetadataProvider implementation delegates to the WinUI controls' built-in provider so that custom control types (TextCommandBarFlyout, etc.) can be instantiated from XBF theme resources."
---

### `OnUnhandledException` [#onunhandledexception]

Optional callback for unhandled exceptions. If set, called before deciding whether to handle. Return true to mark the exception as handled; return false (or leave null) to let it crash.

```csharp
public static Func<Exception, bool>? OnUnhandledException  // get, set
```

**Remarks**

Also receives render errors an app's [`RenderErrorHandler`](/microsoft-ui-reactor/main/reference/components/render-errors#rendererrorhandler) routes here with [`RenderError.Propagate`](/microsoft-ui-reactor/main/reference/components/render-errors#propagate). That call is made by Reactor itself, not by WinUI, so it happens even when the app's `Application` is not a [`ReactorApplication`](/microsoft-ui-reactor/main/reference/hosting/ReactorApplication) (for example a XAML app hosting `ReactorHostControl`). See [`RenderError.Propagate`](/microsoft-ui-reactor/main/reference/components/render-errors#propagate) for what happens when it returns false.
