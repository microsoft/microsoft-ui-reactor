The argument to [`ReactorApp.Run`](/microsoft-ui-reactor/main/reference/hosting/ReactorApp#runactionreactorappcontext)'s startup callback. Carries the launch activation; all surface-management operations (open / find a window or tray icon, register events) go directly through the static [`ReactorApp`](/microsoft-ui-reactor/main/reference/hosting/ReactorApp) API — call sites mix freely. (spec 036 §4.3)

```csharp
public sealed class ReactorAppContext
```

Namespace: `Microsoft.UI.Reactor`.

**Learn more:** [Windows](/microsoft-ui-reactor/main/guides/windows)

## Remarks [#remarks]

Keep the context small on purpose: the static [`ReactorApp`](/microsoft-ui-reactor/main/reference/hosting/ReactorApp) surface is the single source of truth for windows / tray icons / shutdown policy, and remains valid before `Run` enters this callback and after it returns. Doubling the API on the context just doubled the discovery cost without adding capability.
