Returns the current per-window DPI ([`ReactorWindow.Dpi`](/microsoft-ui-reactor/main/reference/hosting/ReactorWindow#dpi)) and re-renders on DPI change. Returns the system primary-monitor DPI when called outside a window. (spec 036 §5.2)

```csharp
public uint UseDpi()
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Advanced Windowing](/microsoft-ui-reactor/main/guides/windowing-advanced), [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected uint UseDpi()
```
