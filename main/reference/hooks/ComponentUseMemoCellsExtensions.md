## Summary [#summary]

`Component`-class shims for [UseMemoCellsExtensions](/microsoft-ui-reactor/main/reference/hooks/UseMemoCellsExtensions) ([guide](/microsoft-ui-reactor/main/guides/hooks))
so subclasses can call `UseMemoCells` without going through
`this.Context`. Same semantics as the `RenderContext`
extension methods.
