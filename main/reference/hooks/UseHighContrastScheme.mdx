---
title: "UseHighContrastScheme"
description: "Returns the high contrast scheme name (e.g., \"High Contrast Black\", \"High Contrast White\") or null if not in high contrast mode. Automatically re-renders the component when the scheme changes."
---

Must be called instead of (not in addition to) [`UseHighContrast`](/microsoft-ui-reactor/main/reference/hooks/UseHighContrast) because each consumes the same hook slots. Use one or the other.

```csharp
public string? UseHighContrastScheme()
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Accessibility](/microsoft-ui-reactor/main/guides/accessibility), [Theming Tokens](/microsoft-ui-reactor/main/guides/theming-tokens), [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected string? UseHighContrastScheme()
```
