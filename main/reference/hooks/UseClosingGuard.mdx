Registers a synchronous "can the window close right now?" predicate. Multiple guards stack — any returning `false` cancels the close. Runs on the UI thread; for async confirmation, return `false` and re-trigger [`ReactorWindow.Close`](/microsoft-ui-reactor/main/reference/hosting/ReactorWindow#close) from the dialog callback. No-op outside a window. (spec 036 §7 / §13.4)

```csharp
public void UseClosingGuard(Func<bool> canClose)
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Windows](/microsoft-ui-reactor/main/guides/windows), [Hooks](/microsoft-ui-reactor/main/guides/hooks)
