> **Learn more:** [Hooks](/microsoft-ui-reactor/main/guides/hooks), [Effects](/microsoft-ui-reactor/main/guides/effects)


## Discussion [#discussion]



Ordering: [OnOptimistic](/microsoft-ui-reactor/main/reference/hooks/MutationOptions) fires
synchronously before the mutator starts. [OnSuccess](/microsoft-ui-reactor/main/reference/hooks/MutationOptions)
or [OnError](/microsoft-ui-reactor/main/reference/hooks/MutationOptions) fires on the hook's dispatcher
thread after completion.



If [OnOptimistic](/microsoft-ui-reactor/main/reference/hooks/MutationOptions) throws, the
mutator is never invoked and the returned task is faulted with the optimistic
exception — prevents half-applied state where the optimistic patch ran but the
real request can't.
