Convenience wrapper — returns `true` when the app-global color scheme is [`ColorScheme.Dark`](/microsoft-ui-reactor/main/reference/theming/enums#values_1). Exactly `UseColorScheme() == ColorScheme.Dark`, so it inherits that hook's semantics: it does not observe per-element `RequestedTheme`.

```csharp
public bool UseIsDarkTheme()
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Theming Tokens](/microsoft-ui-reactor/main/guides/theming-tokens), [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected bool UseIsDarkTheme()
```
