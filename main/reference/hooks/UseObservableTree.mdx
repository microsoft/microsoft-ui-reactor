---
title: "UseObservableTree"
description: "Observes an object and all nested INotifyPropertyChanged values reachable through its properties. Re-renders when any property at any depth changes. Automatically subscribes/unsubscribes as property values change."
---

```csharp
public T UseObservableTree<T>(T source) where T : INotifyPropertyChanged
```
