Returns the app-global [`ColorScheme`](/microsoft-ui-reactor/main/reference/theming/enums#colorscheme) — [`ColorScheme.Light`](/microsoft-ui-reactor/main/reference/theming/enums#values_1) or [`ColorScheme.Dark`](/microsoft-ui-reactor/main/reference/theming/enums#values_1), read from `Application.Current.RequestedTheme`.

The value is re-evaluated on every render — when the app theme changes, [`ReactorHost`](/microsoft-ui-reactor/main/reference/hosting/ReactorHost) triggers a re-render so this hook naturally picks up the new value.

This hook does **not** observe per-element `RequestedTheme` overrides: it consults the application, not the calling component's position in the tree, so a component inside a `.RequestedTheme(Dark)` subtree still reports the app theme. It also never returns [`ColorScheme.HighContrast`](/microsoft-ui-reactor/main/reference/theming/enums#values_1) in a running app — use [`UseHighContrast`](/microsoft-ui-reactor/main/reference/hooks/UseHighContrast) for forced-colors mode.

```csharp
public ColorScheme UseColorScheme()
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Theming Tokens](/microsoft-ui-reactor/main/guides/theming-tokens), [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected ColorScheme UseColorScheme()
```
