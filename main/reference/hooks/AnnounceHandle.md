## Summary [#summary]

Handle returned by [UseAnnounce](/microsoft-ui-reactor/main/reference/hooks/UseAnnounce#useannouncerendercontext) ([guide](/microsoft-ui-reactor/main/guides/hooks)).
Provides an imperative [Announce](/microsoft-ui-reactor/main/reference/hooks/Announce#announcestring) ([guide](/microsoft-ui-reactor/main/guides/hooks)) method for screen reader
live-region announcements plus a zero-size [Region](/microsoft-ui-reactor/main/reference/hooks/Region) ([guide](/microsoft-ui-reactor/main/guides/hooks)) element
that must be included somewhere in the component's rendered tree.
