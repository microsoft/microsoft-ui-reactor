Open (or reuse-by-[`TrayIconSpec.Key`](/microsoft-ui-reactor/main/reference/hosting/tray-icon#key_1)) a system-tray icon scoped to the calling component. The icon closes automatically on unmount — that's the only difference from [`ReactorApp.OpenTrayIcon`](/microsoft-ui-reactor/main/reference/hosting/ReactorApp#opentrayicon), which is app-scoped and keeps the icon alive until explicit [`ReactorTrayIcon.Close`](/microsoft-ui-reactor/main/reference/hosting/tray-icon#close).

```csharp
public ReactorTrayIcon? UseTrayIcon(TrayIconSpec spec)
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Parameters [#parameters]

| Name | Type | Description |
| --- | --- | --- |
| `spec` | [`TrayIconSpec`](/microsoft-ui-reactor/main/reference/hosting/tray-icon#trayiconspec) |  |

## Remarks [#remarks]

Returns `null` when no UI dispatcher has been captured (test contexts) or when the spec change cannot be reconciled — callers should null-check before subscribing to events. Identity-stable across re-renders so the same handle wires through subsequent `UseEffect` dependencies. (spec 036 §11.4)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected ReactorTrayIcon? UseTrayIcon(TrayIconSpec spec)
```
