Returns the [`InfiniteResource<TItem>`](/microsoft-ui-reactor/main/reference/data/paging#infiniteresourcetitem) owned by this hook slot. The resource's state is driven by `fetchPage`; `deps` controls cache-keying and deps-change restart.

```csharp
public static InfiniteResource<TItem> UseInfiniteResource<TItem, TCursor>(this RenderContext ctx, Func<TCursor?, CancellationToken, Task<Page<TItem, TCursor>>> fetchPage, object[] deps, InfiniteResourceOptions? options = null, IHookDispatcher? dispatcher = null, Func<int, TCursor?>? cursorFromPageIndex = null)

protected InfiniteResource<TItem> UseInfiniteResource<TItem, TCursor>(Func<TCursor?, CancellationToken, Task<Page<TItem, TCursor>>> fetchPage, object[] deps, InfiniteResourceOptions? options = null)
```

An extension method on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext), declared in `UseInfiniteResourceExtensions`.

### `UseInfiniteResource<TItem, TCursor>(RenderContext, Func<TCursor?, CancellationToken, Task<Page<TItem, TCursor>>>, object[], InfiniteResourceOptions?, IHookDispatcher?, Func<int, TCursor?>?)` [#useinfiniteresourcetitem-tcursorrendercontext-functcursor-cancellationtoken-taskpagetitem-tcursor-object-infiniteresourceoptions-ihookdispatcher-funcint-tcursor]

Overload that reads the ambient [`QueryCache`](/microsoft-ui-reactor/main/reference/data/query-cache#querycache) from [`AppContexts.QueryCache`](/microsoft-ui-reactor/main/reference/components/AppContexts#querycache). [`ReactorHost`](/microsoft-ui-reactor/main/reference/hosting/ReactorHost) installs a process-wide default cache at startup; tests or subtrees may override it via `.Provide(AppContexts.QueryCache, customCache)`.
