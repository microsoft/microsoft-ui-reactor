Resolves the [`ReactorWindow`](/microsoft-ui-reactor/main/reference/hosting/ReactorWindow) whose host renders this component — including nested components and virtualized rows realized outside the host's render pass — or `null` when it has no owning window (tray-flyout content, `ReactorHostControl` embeds). O(1) field read; no subscription, no re-render trigger. (spec 036 §7 / §7.1)

```csharp
public ReactorWindow? UseWindow()
```

Declared on [`RenderContext`](/microsoft-ui-reactor/main/reference/components/RenderContext).

**Learn more:** [Windows](/microsoft-ui-reactor/main/guides/windows), [Advanced Windowing](/microsoft-ui-reactor/main/guides/windowing-advanced), [Hooks](/microsoft-ui-reactor/main/guides/hooks)

## Use from a class component [#use-from-a-class-component]

Class components can call the same hook directly. These overloads forward to the ones above:

```csharp
protected ReactorWindow? UseWindow()
```
