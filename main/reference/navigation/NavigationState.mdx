A snapshot of a [`NavigationHandle<TRoute>`](/microsoft-ui-reactor/main/reference/navigation/NavigationHandle)'s full state: the back stack, the currently active route, and the forward stack. Obtained from [`NavigationHandle.GetState`](/microsoft-ui-reactor/main/reference/navigation/NavigationHandle#getstate) and restored via [`NavigationHandle.SetState`](/microsoft-ui-reactor/main/reference/navigation/NavigationHandle#setstate).

```csharp
public sealed record NavigationState<TRoute>(IReadOnlyList<TRoute> BackStack, TRoute Current, IReadOnlyList<TRoute> ForwardStack) where TRoute : notnull
```

Namespace: `Microsoft.UI.Reactor.Navigation`.

**Learn more:** [Navigation](/microsoft-ui-reactor/main/guides/navigation)

## Remarks [#remarks]

Reactor intentionally does not pick a serialization format for navigation state. This record is a plain POCO with no serializer-specific attributes — callers can persist it however they like: JSON via `System.Text.Json` (preferably with a source-generated `JsonSerializerContext` for AOT-safety), MessagePack, or by hand. Avoid insecure or obsolete serializers.
