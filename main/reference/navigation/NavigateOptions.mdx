## Properties [#properties]

### `ConnectedAnimationKey` [#connectedanimationkey]

Optional key of the shared element on both pages. Independent of [`NavigateOptions.Transition`](#transition); use [`NavigationTransition.None`](/microsoft-ui-reactor/main/reference/navigation/transitions#none) for shared-element motion without an accompanying page transition. The key and explicit transition are remembered for back/forward navigation within this session, but are not part of serialized navigation state.

### `PushToBackStack` [#pushtobackstack]

When true (default), the current route is pushed onto the back stack. When false, the current route is replaced (no back stack entry created).
