## Types [#types]

| Type | Description |
| --- | --- |
| [Attached layout properties](/microsoft-ui-reactor/main/reference/layout/attached) | Records that hold the attached properties set by the layout modifiers. |
| [Flex enums](/microsoft-ui-reactor/main/reference/layout/flex-enums) | Enums that control the flex layout. |
| [`GridSize`](/microsoft-ui-reactor/main/reference/layout/GridSize) | Strongly-typed grid track size, used by the typed `Microsoft.UI.Reactor.Factories.Grid(GridSize[], GridSize[], Element?[])` factory in place of the legacy string-form (`"Auto"`, `"*"`, `"200"`, `"1.5*"`) tracks. |
| [`GridSizeExtensions`](/microsoft-ui-reactor/main/reference/layout/GridSizeExtensions) | Fluent extension methods for `GridSize` to set the optional `Min` and `Max` properties. |
