## Types [#types]

| Type | Description |
| --- | --- |
| [Attached validation state](/microsoft-ui-reactor/main/reference/validation/attached) | Records that hold the validation state stored on an element. |
| [Enums](/microsoft-ui-reactor/main/reference/validation/enums) | The enumerations in this category. |
| [`ErrorBubbling`](/microsoft-ui-reactor/main/reference/validation/ErrorBubbling) | Helpers for filtering and processing validation messages through the visualizer hierarchy. |
| [`ErrorStyling`](/microsoft-ui-reactor/main/reference/validation/ErrorStyling) | Default error styling configuration. |
| [`FormFieldHelpers`](/microsoft-ui-reactor/main/reference/validation/FormFieldHelpers) | Helpers for FormField rendering logic. |
| [`IAsyncValidator`](/microsoft-ui-reactor/main/reference/validation/IAsyncValidator) | An asynchronous validator for operations that require I/O (e.g., server-side uniqueness checks). |
| [`IValidator`](/microsoft-ui-reactor/main/reference/validation/IValidator) | A synchronous validator that checks a value and returns a validation message on failure. |
| [`Validate`](/microsoft-ui-reactor/main/reference/validation/Validate) | Factory methods for built-in validators. |
| [`ValidateExtensions`](/microsoft-ui-reactor/main/reference/validation/ValidateExtensions) | Fluent extension methods for attaching validation to Reactor elements. |
| [`ValidationContext`](/microsoft-ui-reactor/main/reference/validation/ValidationContext) | Collects, queries, and manages validation messages for a form or section of a component tree. |
| [`ValidationContexts`](/microsoft-ui-reactor/main/reference/validation/ValidationContexts) | Provides the Context definition for propagating ValidationContext through the tree. |
| [`ValidationMessage`](/microsoft-ui-reactor/main/reference/validation/ValidationMessage) | An immutable validation message associated with a specific field. |
| [`ValidationReconciler`](/microsoft-ui-reactor/main/reference/validation/ValidationReconciler) | Helpers for running validation within a component's render cycle. |
| [`ValidationRuleDsl`](/microsoft-ui-reactor/main/reference/validation/ValidationRuleDsl) | DSL factory methods for ValidationRule elements. |
