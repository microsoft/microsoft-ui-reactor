## `ShowWhen` [#showwhen]

Controls when error styling becomes visible.

```csharp
public enum ShowWhen
```

Namespace: `Microsoft.UI.Reactor.Controls.Validation`.

### Values [#values_1]

| Name | Value | Description |
| --- | --- | --- |
| `Always` | `0` | Always show errors, regardless of touched/dirty state. |
| `WhenTouched` | `1` | Only show errors after the field has been focused then blurred. |
| `WhenDirty` | `2` | Only show errors after the field's value has changed from initial. |
| `AfterFirstSubmit` | `3` | Only show errors after the first submit attempt. |
| `Never` | `4` | Never show error styling (errors still exist in context). |
